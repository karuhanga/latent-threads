# Product context

Baseline: 12 September 2026. Current scope is [First playable release](first-release.md); durable state is [CONTEXT.md](../pm/CONTEXT.md). Live ticket tracking is in [Notion](https://www.notion.so/3d907031acb58172be89cad68e89e362).

Latent Threads is an interactive map of how people get things done. The central invitation is “How does X get done?” A learner can start with an endeavor, role, subject, skill or tool and follow contributions into the people, knowledge and learning behind it. Careers are an important route through the experience. The initial audience is curious high-school learners and adults.

The user confirmed a song first, coffee from Uganda to a European café second. The other seed endeavors—skyscraper, emergency care, satellite and mobile app—stress-test the model now and become content later. The name is provisional; “See how the world gets done” remains proposed copy.

## Wave 1

One sourced song journey, roughly 30–50 browsable entities: 5–7 stages, 6–10 roles and 8–12 related skills/concepts/tools, with contextual contributions and at least three checked learning resources across two concepts. These are coverage targets, not permission to invent entries.

Three checkpoints: visual foundation; follow a song through stages and contributions; discovery/search/trails with contextual learning and a verified production preview. A five-minute review should find two distinct contributions, explain one relationship, reach an unfamiliar concept, open a useful learning resource and return without losing orientation.

Home uses a mixed Curiosity Wall and “How does X get done?” search. Exploration shows a bounded neighborhood and clear connection labels. Typography, flat accents, generous whitespace and purposeful movement take inspiration from Windows Phone. Mobile layouts, keyboard access, reduced motion and legible labels are essential.

## Data commitments

An artifact is distinct from the endeavor that makes it. Roles are broader than occupations. Contributions bind an action and role to an endeavor/stage. Team relationships are contextual. Knowledge, capabilities/skills and tools remain meaningfully distinct.

Use stable IDs, typed relationships, provenance and honest evidence labels. Free access and open licensing are independent. Do not promote illustrative salary, history or geography examples into data. The v0.1 ontology defines the implementation contract.

World/Africa/Kenya/Uganda are the first geographic scopes; Kenya and Uganda are siblings. Missing verification is unknown, never proof of absence. Geography/time enter the schema early, but the geography UI follows sourced coffee content in Wave 2.

## Deferred

Accounts, sync, generative chat, assessments, user editing, salary dashboards, bulk occupation imports, historical slider, full semantic zoom, automatic tile flipping, persistent/shared trails and offline reopening are separate future decisions. Start with a small read-only static app using bundled JSON. No database service is needed for the first release.
