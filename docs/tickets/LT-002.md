# LT-002 — Define and review the minimal ontology v0.1

[Live kanban card](https://app.notion.com/p/3d907031acb581138900c49142fbeac2?pvs=204) · Wave 1 · B — Follow a song

## Objective
Give data and UI agents a small shared contract that can explain how work gets done.
## Scope
Draft [ontology-v0.1.md](../product/ontology-v0.1.md) with normalized entity, relation and contribution records, stable IDs, provenance, geography evidence, optional temporal precision and a clearly illustrative song fixture. Check the model against all six original endeavors.
## Acceptance criteria
- [ ] Distinguish endeavor/artifact, role/occupation mapping, activity/capability/skill/knowledge/tool without making every word a table.
- [ ] A contribution binds a role and action to an endeavor/stage; cardinality and collaboration derivation rules are explicit.
- [ ] Geography supports World/Africa and sibling Kenya/Uganda with dated evidence and unknown states; temporal fields support partial dates without fictional precision.
- [ ] Song example is explicitly illustrative and includes at least one multi-hop learning path. All six endeavor stress tests record a concrete modeling challenge.
- [ ] Define invalid endpoint/context/provenance cases and the Wave 1 subset; PM reviews before LT-005/LT-006 start.
## Dependencies
None.
## Verification
PM reads the proposed contract against source user turns 2–4 and all six stress tests; executable validation is LT-005.
## Out of scope
No verified seed dataset, data imports, ontology editor or full historical model implementation.
## Handoff
Ticket status and acceptance evidence are tracked in Notion; these unchecked boxes define the contract, not a live progress mirror.
Planned role: Data model. Size: M — about 1 day. Estimates indicate focused engineering effort, not a calendar commitment.
When starting, set an actual Agent, move to In progress and name files owned. For review, attach exact changed files/commit, relevant check results and a visible preview when applicable. PM checks acceptance before Done.
