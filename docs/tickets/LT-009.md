# LT-009 — Surface useful learning resources and evidence in context

[Live kanban card](https://app.notion.com/p/3d907031acb581ada0ede6e313beb672?pvs=204) · Wave 1 · C — Discover and learn

## Objective
Turn an interesting discovery into an approachable next learning step.
## Scope
Render role/concept details, relationship evidence and learning cards from the curated records in the explorer’s detail panel.
## Acceptance criteria
- [ ] At least three checked learning cards appear under the relevant concepts, with provider, title and learner level.
- [ ] Access cost and reuse license are distinct fields; unknown licensing is explicit and never labelled openly licensed by inference.
- [ ] A learner can see the source behind a substantive displayed connection; checked dates are available where useful.
- [ ] External resources open safely without losing exploration state; empty learning/evidence states are honest.
- [ ] No invented duration, salary, prerequisite or qualification fields are shown to fill the layout.
## Dependencies
[LT-007](LT-007.md)
## Verification
Walk from a contribution to a concept and open its learning link, return with state intact, inspect license/access variants and keyboard behavior.
## Out of scope
No enrollment, course hosting, assessment engine or education recommendation claims.
## Handoff
Ticket status and acceptance evidence are tracked in Notion; these unchecked boxes define the contract, not a live progress mirror.
Planned role: UI. Size: S — up to half day. Estimates indicate focused engineering effort, not a calendar commitment.
When starting, set an actual Agent, move to In progress and name files owned. For review, attach exact changed files/commit, relevant check results and a visible preview when applicable. PM checks acceptance before Done.
