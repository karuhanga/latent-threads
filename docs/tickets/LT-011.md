## Objective
Give each reviewed increment a simple hosted demo with no backend operations.
## Scope
Use the existing public repository karuhanga/latent-threads. After LT-003 produces the app build, run checks/build locally and publish only the contents of dist plus .nojekyll to the root of a gh-pages branch. A separate repository and custom Actions build workflow are unnecessary for this first route.
