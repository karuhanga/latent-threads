# LT-004 — Build the Windows Phone inspired visual shell

[Live kanban card](https://app.notion.com/p/3d907031acb5814ca96df3649d5a24f8?pvs=204) · Wave 1 · A — Visual foundation

## Objective
Let Lincoln see and steer the visual direction before the exploration implementation grows.
## Scope
Implement home/Curiosity Wall, endeavor canvas and detail-panel compositions with a small labeled fixture. Establish typography, spacing, flat accent colors, focus and motion tokens. Provide a simple navigable local preview.
## Acceptance criteria
- [ ] Home and explorer states show typography-led, flat-color layouts with generous space and clear hierarchy.
- [ ] 360px mobile and desktop views remain readable and usable; no horizontal page overflow.
- [ ] Keyboard focus and type labels work without relying on color; reduced motion disables decorative transitions.
- [ ] Fixture content is visibly a prototype; there are no dead feature buttons for deferred lenses.
- [ ] Attach desktop/mobile screenshots and preview steps; PM requests optional visual feedback at Checkpoint A.
## Dependencies
[LT-003](LT-003.md)
## Verification
Inspect desktop/mobile preview, keyboard order, visible focus and reduced-motion mode.
## Out of scope
No complex graph physics, full semantic zoom, persistent six-lens system or automatic tile flipping.
