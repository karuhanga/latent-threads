# LT-007 — Deliver the song process and contextual exploration loop

[Live kanban card](https://app.notion.com/p/3d907031acb5813f92d2ef9ed574a2bb?pvs=204) · Wave 1 · B — Follow a song

## Objective
Make the central product promise playable: follow how a song gets done through people and knowledge.
## Scope
Endeavor overview, stage selection, contextual contributions and a focusable bounded neighborhood of connected roles, knowledge and tools. Provide System/Team views or equivalent clearly labeled arrangements backed by the same data.
## Acceptance criteria
- [ ] A learner can traverse endeavor → stage → contribution/role → knowledge/tool and continue to related seeded entities.
- [ ] Each transition labels why the relationship exists and retains contribution context; never infer universal role-to-role collaboration.
- [ ] Selected focus is visually distinct; home/back/reset recover orientation. Empty connections show a useful state.
- [ ] Avoid showing the entire graph; re-center without losing readable labels or focus. Keyboard companion list reaches equivalent content.
- [ ] Works with actual validated song data at mobile and desktop sizes; attach a short demo path for Checkpoint B.
## Dependencies
[LT-004](LT-004.md), [LT-005](LT-005.md), [LT-006](LT-006.md)
## Verification
Manually walk at least two distinct role paths, test context-sensitive relationships and inspect keyboard/mobile behavior.
## Out of scope
No graph authoring UI, physics-heavy global visualization, multi-endeavor knowledge map or time slider.
## Handoff
Ticket status and acceptance evidence are tracked in Notion; these unchecked boxes define the contract, not a live progress mirror.
Planned role: UI. Size: L — up to 2 days. Estimates indicate focused engineering effort, not a calendar commitment.
When starting, set an actual Agent, move to In progress and name files owned. For review, attach exact changed files/commit, relevant check results and a visible preview when applicable. PM checks acceptance before Done.
