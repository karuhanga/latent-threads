# LT-008 — Add mixed discovery, search and recoverable exploration trails

[Live kanban card](https://app.notion.com/p/3d907031acb581d8a81aeaf012acbca1?pvs=204) · Wave 1 · C — Discover and learn

## Objective
Let learners enter from their own curiosity and move around without getting lost.
## Scope
Populate the Curiosity Wall from real seed content, case-insensitive label/alias search, manual shuffle/Surprise me, visible session trail and stable hash URLs for focal nodes.
## Acceptance criteria
- [ ] Search returns seeded endeavors, roles, knowledge and tools with clear type labels; partial/alias matching and a useful no-result state work.
- [ ] Every Curiosity Wall/Surprise me target opens actual available content, with no fabricated breadth.
- [ ] Trail entries navigate back to earlier focus/context; browser back/forward behave consistently.
- [ ] Opening or refreshing a /latent-threads/#/… link restores the focal node; unknown or retired IDs recover helpfully.
- [ ] Use search/navigation without a pointer. Interaction feedback remains immediate on the small bundled dataset.
## Dependencies
[LT-007](LT-007.md)
## Verification
Test representative multi-type/alias/no-result queries, a three-hop trail, browser back/forward and deep-link refresh on a static subpath preview.
## Out of scope
No natural-language AI search, accounts, persistent bookmarks or shareable multi-step trail serialization.
## Handoff
Ticket status and acceptance evidence are tracked in Notion; these unchecked boxes define the contract, not a live progress mirror.
Planned role: UI. Size: M — about 1 day. Estimates indicate focused engineering effort, not a calendar commitment.
