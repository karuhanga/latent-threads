## Objective
Make a fresh checkout runnable and buildable before feature work begins.
## Scope
Vite + React + TypeScript, Node 24, one package manager and committed lockfile. Scripts for dev, typecheck, test and production build. Readme, ignore rules, hash route entry and static base configuration. Local Git is already initialized; complete scaffold in this ticket.
## Acceptance criteria
- [ ] A fresh install using the lockfile starts the app and builds dist with documented commands; runtime version is pinned in repo and CI configuration.
- [ ] Use the bundled runtime if system Node is absent; no paid service or backend dependency.
- [ ] Add narrowly scoped CI checks for types, relevant tests, data validation once LT-005 lands, and production build.
- [ ] Ignore new local exports, OS/IDE clutter, secrets, dependencies and build output; preserve ideation already tracked in Lincoln’s initial commit. Repo includes a concise context document for future agents.
- [ ] Production output works at a configurable repository subpath; invalid route recovers to home.
## Dependencies
None.
