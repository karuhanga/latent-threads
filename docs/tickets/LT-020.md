# LT-020 — Refine discovery and independent connections from user review

[Notion tracking](https://www.notion.so/3d907031acb581f39b76e971497b4ab5)

## Objective
Turn the song-framed prototype into a direct catalog explorer with an animated mixed tile wall and uncluttered details.

## User direction — 12 September 2026
Search must clearly search the catalog, not songs/artists. Home is primarily a screen of large/small randomly arranged endeavor and connected-item tiles; automatic Windows Phone style shuffling and manual global Shuffle/Surprise remain. Remove song-specific home/header copy and the closing slogans. Sources/attribution move behind a discreet settings control, off by default. Remove visible trail. Stages belong to endeavors; roles, skills, knowledge and tools are independently connected entities. Replace generated “person at work” names with conventional activity names, e.g. Production, while preserving actual role names.

## Acceptance
- Home has no song-specific hero, slogans, numbering or sample trail. Catalog search explicitly covers endeavors, activities, roles, skills, concepts and tools; empty state is generic.
- Mixed large/small tiles use actual published catalog entries. Layout/content shuffle roughly every seven seconds, with staggered tile flip/slide motion. Keep tile destinations stable during pointer/keyboard interaction; pause for hover/focus, hidden document, user pause and reduced motion. Manual Shuffle/Surprise use the whole catalog. No fake additional endeavors; current data contains one endeavor, architecture can consume more.
- Small accessible Settings control toggles detailed source/attribution info (default off) and automatic shuffle. Store only display preferences locally with safe storage fallback. Learning title/provider/level/access and concise factual descriptions remain useful without audit clutter.
- No visible trail or forced song breadcrumb, song reset or universal process/team controls on standalone entities. Process stages remain on endeavor/stage/contribution pages using their actual endeavor. Browser back and refreshed focal links work.
- Conventional activity labels replace generated at-work names; role and activity remain distinct. All real source records/validators remain intact. Sources and reuse metadata can be inspected when enabled.
- Mobile/keyboard and motion behavior reviewed, regression checks pass, revised build deployed and exact source recorded.
